# Kurage 要介護認定ナビ（knintei）

**要介護認定の調査で、何を聞かれるか。** 認定調査の55問を、選択肢と定義つきで見られます。
文言は厚生労働省の認定調査票のまま、言い換えていません。

- デモ: https://kurage.exbridge.jp/knintei.php/
- 設問 55問・選択肢 181個・市区町村ページ 1,912枚
- PHP 1ファイル＋SQLite 1本（516KB）

## 要介護度は判定しません

区分は要介護認定等基準時間で決まり、その時間は「**厚生労働大臣の定める方法により推計される時間**」と
省令3条が定めています。この方法＝一次判定ソフトの係数は公開されていないので、
公開データから同じ計算は再現できません。

「目安です」と書いて数字を出すこともできますが、区分が変われば支給限度額が変わります。
**境目と根拠の条文までを出して止めています。**

| 区分 | 要介護認定等基準時間 |
|---|---|
| 要支援1 | 25分以上32分未満 |
| 要支援2 / 要介護1 | 32分以上50分未満（分かれるのは状態の維持・改善の見込み） |
| 要介護2 | 50分以上70分未満 |
| 要介護3 | 70分以上90分未満 |
| 要介護4 | 90分以上110分未満 |
| 要介護5 | 110分以上 |

## 画面

| パス | 内容 |
|---|---|
| `/` | 認定調査55問の一覧表＋区分の境目。言葉で項目を探せる |
| `/item/<n-m>` | 項目1つ。選択肢・**調査項目の定義**・**選択肢の選択基準**を原文のまま |
| `/group/<1-5>` | 群ごと（身体機能13・生活機能12・認知機能9・精神行動15・社会適応6） |
| `/kubun` | 区分の境目と、当てない理由（省令1〜3条の条文） |
| `/nagare` | 申請から認定まで（介護保険法27条・30日以内） |
| `/city/<都道府県>/<市区町村>` | 申請の窓口＋その市区町村の65歳以上人口・高齢化率の全国順位 |
| `/pref/<都道府県>` / `/cities` | 市区町村の索引 |
| `/api/items`, `/sitemap.xml`, `/llms.txt` | API・SEO/AEO |

## データ

詳しくは docs/DATA.md。出所とライセンス、踏んだ罠を書いてあります。

## 作り直し方

```bash
/usr/bin/python3 scripts/fetch_law.py      # 条文（5法令）
/usr/bin/python3 scripts/parse_items.py    # 認定調査55問（74項目の検算つき）
/usr/bin/python3 scripts/parse_detail.py   # 定義と選択基準
/usr/bin/python3 scripts/fetch_cities.py   # 市区町村（総務省）
/usr/bin/python3 scripts/fetch_age.py      # 65歳以上人口（総務省）
/usr/bin/python3 scripts/build_db.py
/usr/bin/python3 scripts/selftest.py       # 画面を実際に叩く（18件）
/usr/bin/python3 scripts/shot.py           # 320/360/390/430px の横はみ出し
/usr/bin/python3 scripts/deploy.py
```

`parse_items.py` は「74項目」の内訳（麻痺5・拘縮4に展開して62＋特別な医療12）を毎回計算し、
74にならなければ止まります。
