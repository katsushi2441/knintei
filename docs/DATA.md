## いちばん大事な線：区分は予測しない

要介護度の区分は、**要介護認定等基準時間**で決まる。その境目は省令に全部書いてある。

| 区分 | 要介護認定等基準時間 |
|---|---|
| 要支援1 | 25分以上32分未満 |
| 要支援2 | 32分以上50分未満（状態の維持・改善の見込みがある場合） |
| 要介護1 | 32分以上50分未満 |
| 要介護2 | 50分以上70分未満 |
| 要介護3 | 70分以上90分未満 |
| 要介護4 | 90分以上110分未満 |
| 要介護5 | 110分以上 |

出典: 要介護認定等に係る介護認定審査会による審査及び判定の基準等に関する省令 1条・2条。

**では基準時間はどう出すのか。** 同じ省令の3条にこうある。

> 当該被保険者に対して行われる次に掲げる行為に要する一日当たりの時間として、
> **厚生労働大臣の定める方法により推計される時間**とする。

この「厚生労働大臣の定める方法」が一次判定ソフトの樹形モデルで、**係数は公開されていない**。
だから、このシステムは区分を当てない。**境目と根拠だけを出す。**
「あなたは要介護2です」と書けば、支給限度額が変わる話に嘘をつくことになる。

なお基準時間が対象とする行為も3条に列挙がある（入浴・排せつ・食事等の介護／洗濯・掃除等の
家事援助等／徘徊に対する探索、不潔な行為に対する後始末等／歩行訓練、日常生活訓練等の機能訓練／
輸液の管理、じょく瘡の処置等の診療の補助等）。「掃除をしてもらう時間」ではなく
「介護の手間の総量」だと分かるので、これは画面に出す。

## 「74項目」の数え方

設問は第1群から第5群までで**55問**しかない。74になるのは数え方が違うため。

| | |
|---|---|
| 第1群 身体機能・起居動作 | 13問 |
| 第2群 生活機能 | 12問 |
| 第3群 認知機能 | 9問 |
| 第4群 精神・行動障害 | 15問 |
| 第5群 社会生活への適応 | 6問 |
| 小計 | **55問** |

ここで **1-1 麻痺等の有無を部位ごとに5、1-2 拘縮の有無を4**と数えると 55 − 2 + 9 = **62**。
これに**その他（過去14日間にうけた特別な医療）12項目**を足して **74**。

障害高齢者・認知症高齢者の日常生活自立度2つは74の外（一次判定には使わない）。

`parse_items.py` はこの計算を毎回して、74にならなければ止まる。

## 取り込みで踏んだ罠

**選択肢の区切りに空白があるとは限らない。** 5-3 日常の意思決定は
「1.できる（特別な場合でもできる）2.特別な場合を除いてできる」と詰まっていて、
空白2つを区切りにしていたら選択肢が1つも取れなかった。

**「（複数回答可）」は見出しの行内にあるとは限らない。** 1-2 拘縮は次の行に折り返している。
逆に、区切りの後ろまで見ると次の節（特別な医療）の「複数回答可」を拾って、
5-6 簡単な調理が複数回答になった。→ 見出し行の「すべてに○印」「一つだけ○印」で決める。

**項目名も選択肢も言い換えない。** 認定調査は選択肢の文言そのものが判断基準になっている
（「つかまらないでできる」と「何かにつかまればできる」の差がそのまま点になる）。要約すると別物になる。

## 市区町村ごとの固有の事実

**65歳以上の人数と割合**を使う。介護保険の第1号被保険者は65歳以上（介護保険法9条1号）なので、
その市区町村で認定を申請しうる人の土台にあたる。

全国で人口123,767,642人・65歳以上35,898,611人（**29.0%**）。中央値は9,477人・35.2%。
政令市は「市の計」と「区」が二重に入るので、順位を出すときは市の計を外す
（kacnavi で人口動態を二重に数えて全国192万人になった前例）。

北方領土6村は役所が機能していないので除外する。
