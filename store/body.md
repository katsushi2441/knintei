要介護認定の認定調査で、**何を聞かれるか**を見られるシステムです。

「要介護認定」は月に33,100回検索されています。ただ、出てくるのは制度の説明ばかりで、**当日いきなり聞かれて答えに困る55問の中身**が、選択肢の文言まで載っている場所がほとんどありません。

■ 認定調査の55問を、原文のまま

第1群 身体機能・起居動作13問、第2群 生活機能12問、第3群 認知機能9問、第4群 精神・行動障害15問、第5群 社会生活への適応6問。これに過去14日間にうけた特別な医療12項目。

各項目に、厚生労働省の認定調査員テキストから次の3つをそのまま載せています。

1. **選択肢**（「1.つかまらないでできる」「2.何かにつかまればできる」「3.できない」）
2. **調査項目の定義**（「寝返り」とは、きちんと横向きにならなくても、横たわったまま左右のどちらかに身体の向きを変え…）
3. **選択肢の選択基準**（どういうときにどれを選ぶか）

**言い換えていません。** 認定調査は選択肢の文言そのものが判断の基準になるからです。「つかまらないでできる」と「何かにつかまればできる」の差が、そのまま結果に効きます。読みやすく直すと、別のものになります。

■ 「74項目」の数え方も書いてあります

設問は55問しかありません。74になるのは、**麻痺の有無を部位ごとに5、拘縮の有無を4と数えて62、それに特別な医療12を足す**からです。この計算はデータを作り直すたびに自動で検算され、74にならなければ止まります。

■ 要介護度は判定しません

ここが他と違うところです。**区分を当てる機能を、あえて付けていません。**

区分は要介護認定等基準時間で決まります。その時間は省令3条で「**厚生労働大臣の定める方法により推計される時間**」と定められていて、この方法＝一次判定ソフトの係数は公開されていません。公開データから同じ計算を再現することはできません。

「目安です」と書いて数字を出すこともできますが、区分が変われば支給限度額が変わります。外したときに困るのは使う人です。だから境目と根拠の条文までを出して止めています。

| 区分 | 要介護認定等基準時間 |
|---|---|
| 要支援1 | 25分以上32分未満 |
| 要支援2 / 要介護1 | 32分以上50分未満 |
| 要介護2 | 50分以上70分未満 |
| 要介護3 | 70分以上90分未満 |
| 要介護4 | 90分以上110分未満 |
| 要介護5 | 110分以上 |

**要支援2と要介護1は時間が同じ**で、状態の維持・改善の見込みがあるかどうかで分かれます（省令2条1項2号）。よく聞かれるところなので、条文つきで1ページにしてあります。

■ 市区町村ごとのページ

全国1,912市区町村（政令指定都市20市の区と東京23区を含む）ぶんのページがあります。申請の窓口の説明と、その市区町村に65歳以上が何人いて、高齢化率が全国で何番目かが出ます。

政令指定都市は**区役所が窓口**なので、市で1本にまとめず区ごとに分けています。

■ 置き方

1. knintei.php と knintei_data/ を置く
2. その階層の .htaccess に AddHandler php-script .php を書く
3. ブラウザで開く

PHP 8 と PDO SQLite だけで動きます。データベースサーバーも常駐プロセスもポートも要りません。

地域包括支援センター、居宅介護支援事業所、市区町村の窓口が、相談の場でそのまま開いて「当日はこういうことを聞かれます」と見せる使い方を想定しています。自分の市区町村の窓口名・電話・様式のリンクを足せます。

■ しないこと

- **要介護度を判定しません。** 認定は市区町村の介護認定審査会が行います
- **市区町村の課名・電話・受付時間・様式は載せていません。** 市区町村ごとに違い、公式サイトの本文を転載しない方針です
- 認定結果への不服申立てや区分変更の見通しは判断しません

■ データを新しくする

同梱のPythonを動かせば、最新の資料で作り直せます。

```
python3 scripts/fetch_law.py      # 条文（e-Gov法令検索・5法令）
python3 scripts/parse_items.py    # 認定調査55問（74項目の検算つき）
python3 scripts/parse_detail.py   # 定義と選択基準
python3 scripts/fetch_cities.py   # 市区町村（総務省）
python3 scripts/fetch_age.py      # 65歳以上人口（総務省）
python3 scripts/build_db.py
python3 scripts/selftest.py       # 画面を実際に叩いて中身を見る（18件）
```
